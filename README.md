корректное удаление установленных модов(не надо искать в папках игры файлы для удаления,программа сама всё подчистит)
поддержка Archive Invalidation
запуск игры.
Как использовать Nexus Mod Manager:
Чтоб добавить мод перейдите на вкладку "Mods"
На открытой вкладке нажмите на кнопку "Add Mod from file", которая находится в левой стороне окна
В открытом окне выбирите архив мода или папку с модификацией. Поддерживаемая модификация появляется в основном окне программы
Далее, нажмите "Activated the selected mod", чтобы активировать мод в игру, также можно просто дважды щелкнуть по необходимой модификации
Мод установлен
Удаление модов, через Nexus Mod Manager:

Выбирите желаемый мод в общем списке модификации
Нажмите кнопку "Diactivates the selected mod" для его отключения из игры
Установка менджера и настройки
Скачайте желаему версию Nexus Mod Manager (NMM). Как правило, новые версии обладают лучшей поддежкой, но в некоторых играх старые версии могут быть более стабильными. NMM совместим с Windows 7, 8, 10 и 11.
Запустите установщик, дважды щелкнув по .exe файлу и следуйте инструкциям мастера установки.
